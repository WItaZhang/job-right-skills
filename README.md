# career-scout-skills

以偏好访谈和可核实证据为起点的求职 agent skills 项目。

当前阶段：**参考研究**。已筛选 5 个开源项目，记录来源、固定版本、许可证、
核实时间、适合借鉴的部分及局限。入口：[reference/README.md](reference/README.md)。

目标流程：兴趣/人生方向/压力与风险容忍度/硬约束/软偏好访谈 → 澄清冲突 →
研究公司 → 研究团队 → 核实当前 opening → 给出附来源与置信度的匹配理由。

项目目前没有真实个人档案、岗位推荐或自动投递功能；第三方示例不代表用户经历。
下一步先定义 preference profile 和访谈验收案例，再决定工具依赖。
未安装或运行参考项目，也没有代用户投递或联系公司。

本仓库原创文档采用 MIT。第三方项目保留各自许可证；reference/ 仅含原创比较笔记
和指向上游的链接，没有复制上游代码或完整文档。
