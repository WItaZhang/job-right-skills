# 用示例对比澄清偏好

一手资料：B. Faltings、P. Pu、P. Viappiani，*Preference-based Search using Example-Critiquing with Suggestions*，JAIR 27, 465–503（2006）。
[作者论文存档](https://arxiv.org/abs/1110.0026v1) · [出版 DOI](https://doi.org/10.1613/jair.2075)。arXiv 收录于 2011，不是论文首次发表年份。

核实日期：2026-09-22（America/Los_Angeles）。本次阅读摘要和书目信息；没有复现论文实验或审读全部推导。

## 可借鉴机制

用户通过批评、比较具体候选逐步补充偏好，比一次性假定偏好完整更贴近交互决策。摘要讨论利用建议选项帮助用户表达尚未说出的偏好。

## 不应照搬之处

论文的实验结果不能直接转成求职推荐收益；不能把系统猜到的潜在偏好当成已确认条件。选项表述可能影响用户选择，不能通过隐藏取舍替用户决定。

## 对 job-right-skills 的映射

遇到冲突时给 2–3 个中性、具体、标为 synthetic 的情境，让用户解释愿意牺牲什么；允许“都不接受”“暂不知道”。只有用户明确确认后才更改 profile，并记录旧值、新值、适用范围与来源。

例如：“完全远程但业务兴趣一般”与“业务很喜欢但每周需到办公室”可用于澄清远程要求是否绝对；这是本项目原创访谈例子，不是论文的求职实验，也不是给用户推荐实际岗位。

置信度：中；核心交互思想来自论文摘要，具体访谈设计仍需未来使用者验证。
